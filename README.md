## Что здесь будет

Bilem состоит из трёх частей. Две из них открытые.

| Компонент | Что делает | Лицензия |
|---|---|---|
| **`bilem.cfe`** — расширение 1С | HTTP-сервис `/hs/bilem/v1`: остатки, долги, продажи, документы, печатные формы. Только свои объекты, без `&Вместо/&После` — переживает обновления конфигурации. | MIT, этот репо |
| **`bilem-mcp`** — MCP-сервер | Та же 1С как инструмент для Claude, Cursor, ChatGPT, OpenClaw, Hermes. Ходит в HTTP-сервис расширения. | MIT, этот репо |
| **`bilem-agent`** — служба Windows | WhatsApp, память, напоминания, автообновление, одно исходящее соединение в облако Bilem. | закрытый код, платные тарифы |

Расширение открытое намеренно: вы, ваш бухгалтер и ваш 1С-ник можете прочитать, что именно оно читает из базы и что никуда не отправляет. Вся «магия» — в облаке и в агенте.

## Принципы

- **Zero-data.** База остаётся у вас. Запрос к 1С выполняется на вашей стороне; в облако уходит вопрос и ответ.
- **Учёт не трогаем.** Расширение читает; запись — только по явной команде и только на тарифе Pro.
- **Белый список.** Агент отвечает только номерам, которые добавили вы.
- **Переживает обновления 1С.** Никаких перехватов типовых процедур — только HTTP-сервис, свои регистры и общие модули.

## Developer — бесплатно, без нашего агента

Для 1С-разработчиков, франчайзи и тех, кто хочет подключить свою 1С к своему агенту без посредников:

1. Поставить `bilem.cfe` в базу (Конфигуратор → Расширения), опубликовать HTTP-сервис на Apache/IIS.
2. Запустить `bilem-mcp` с адресом сервиса и API-ключом из настроек расширения.
3. Подключить MCP к Claude / Cursor / OpenClaw / Hermes. Ключ LLM — ваш, запросы идут с вашей машины.

Способы дотянуться до 1С, не открывая портов наружу:

| Способ | Когда | Цена |
|---|---|---|
| **Локально** | MCP на той же машине, что и 1С — `http://localhost/base/hs/bilem/v1` | — |
| **Tailscale** | 1С в офисе или дома, агент на вашем ноутбуке; всё внутри tailnet | бесплатно до 3 пользователей |
| **Cloudflare Tunnel + Access** | нужен доступ из браузера или облачного агента | бесплатно |

Скилл для OpenClaw и Hermes — тоже здесь, бесплатно.

## Поддерживаемые конфигурации

Старт — **Бухгалтерия для Казахстана 3.0** (платформа 8.3, файловая и серверная). Дальше — УТ и ЗУП для Казахстана.

## Контракт API (v1, черновик)

```
GET  /hs/bilem/v1/ping        версия платформы, конфигурации, расширения
GET  /hs/bilem/v1/balance     деньги по счетам и кассам
GET  /hs/bilem/v1/debtors     дебиторы и кредиторы
GET  /hs/bilem/v1/invoices    счета за период
GET  /hs/bilem/v1/sales       продажи за период
POST /hs/bilem/v1/invoice     выставить счёт (черновик)        — Pro
GET  /hs/bilem/v1/print/:doc  печатная форма в PDF
GET  /hs/bilem/v1/events      очередь событий (поступления, новые документы)
```

Авторизация — API-ключ в заголовке `X-Bilem-Key`. Ответы — JSON. Полная спецификация появится в `docs/api.md` вместе с первым релизом.
