# Безопасность

Bilem Agent работает с данными 1С на компьютере клиента, поэтому к уязвимостям относимся серьёзно.

## Как сообщить

**Не создавайте публичный issue.** Напишите через [Report a vulnerability](https://github.com/skp-kz/bilem.ai/security/advisories/new) на GitHub.

Укажите: версию Bilem Agent («Сервис» → «Обновления»), Windows, платформу и конфигурацию 1С, шаги воспроизведения. Ответим в течение 3 рабочих дней, исправление критичных проблем — приоритет над всем остальным. Укажем вас в релизе, если хотите.

*English:* please do not open a public issue — use [Report a vulnerability](https://github.com/skp-kz/bilem.ai/security/advisories/new).

## Что считаем уязвимостью

- Доступ к данным 1С через агент без токена MCP или с другого компьютера (OData и MCP слушают только 127.0.0.1).
- Доступ ИИ к объектам, выключенным на вкладке «Доступ», к персональным данным, к удостоверению личности (оно — только внутри PDF доверенности).
- Возможность изменить учёт: провести или удалить документ, записать в объект вне белого списка.
- Утечка пароля пользователя `bilem`, токена MCP, пароля почты или данных 1С в журналы, ответы MCP, письма, сеть.
- Отправка письма в обход правил: доверенность — не на «Список адресов для отправки доверенностей», в обход лимитов или выключенной почты.
- Установка обновления с неверной подписью (`SHA256SUMS.sig`), чужим хешем или чужим издателем Authenticode.

## Что не считаем

- Проблемы в самой платформе 1С, IIS или Windows — сообщайте вендору.
- Уязвимости, требующие уже скомпрометированного компьютера или прав администратора на нём.

## Как защищён Bilem Agent

- **Учёт не меняется**: кода проведения и удаления документов в программе нет; пользователь `bilem` получает самые узкие роли на чтение.
- **Только этот компьютер**: OData — на 127.0.0.1, MCP-сервер — 127.0.0.1 и токен; запросы из браузера (заголовок Origin) отклоняются.
- **Секреты** — зашифрованы для этого компьютера (DPAPI) в `C:\ProgramData\Bilem`, доступ — Администраторы и SYSTEM. Пароль администратора 1С не сохраняется.
- **Журнал аудита** печати и отправки — кто запросил и хеш файла, без содержимого документов.
- **Обновления** подписаны Ed25519; агент проверяет подпись и хеш MSI до установки, при подписи Authenticode — и издателя «SKP.kz LLC».

## Поддерживаемые версии

Исправления выходят только для последнего релиза. Обновляйтесь: «Сервис» → «Обновления».
