# Правила общения

Коротко: мы здесь, чтобы сделать агента для 1С лучше. Уважайте друг друга.

- Вопросы новичков — нормальные вопросы. Отвечаем по делу или направляем в документацию, без «учите матчасть».
- Критикуем код, не людей.
- Без спама, рекламы своих услуг в issues и обсуждениях (для этого есть категория «Партнёры»).
- Русский, казахский, английский — любой.

Нарушения — модераторы предупреждают, при повторе блокируют. Жалобы — на hello@bilem.ai.
