# Как участвовать в bilem.ai

Спасибо, что заглянули. Проект открытый (MIT), и помощь нужна в трёх местах: расширение `bilem.cfe`, MCP-сервер `bilem-mcp` и документация.

## С чего начать

- Вопросы «как подключить», «не работает на моей конфигурации» — в [Discussions → Вопросы](https://github.com/skp-kz/bilem.ai/discussions/categories/q-a). Issues — только для подтверждённых ошибок и запросов функций.
- Идеи новых функций агента («хочу, чтобы отвечал про…») — [Discussions → Идеи](https://github.com/skp-kz/bilem.ai/discussions/categories/ideas). Там голосуем, что делать первым.
- Нашли уязвимость — **не** в публичный issue, см. [SECURITY.md](SECURITY.md).

## Структура

| Папка | Что | Язык |
|---|---|---|
| `cfe/` | расширение 1С: HTTP-сервис `/hs/bilem/v1`, роль «Bilem» (чтение) | 1С (BSL), выгрузка в файлы |
| `mcp/` | MCP-сервер: инструменты для Claude / Cursor / OpenClaw поверх того же API | TypeScript, Node 20 |
| `docs/` | контракт API, инструкции по установке | Markdown |

Контракт между частями — `docs/api-v1.md`. Любое изменение API сначала правится там, потом в коде.

## Окружение

**cfe:** платформа 1С 8.3.24+, конфигурация «Бухгалтерия для Казахстана 3.0» (демо-база подходит). Расширение разрабатывается в Конфигураторе или EDT, в репо лежит выгрузка в файлы:

```
1cv8 DESIGNER /F <база> /N Admin /DumpConfigToFiles cfe/src -Extension bilem
1cv8 DESIGNER /F <база> /N Admin /LoadConfigFromFiles cfe/src -Extension bilem /UpdateDBCfg
```

**mcp:** `cd mcp && npm i && npm run check` — проверка типов; `npm run dev -- --url http://localhost/demo --key …` — локальный запуск.

## Правила

1. **Только чтение.** Расширение не пишет в базу и не меняет конфигурацию. PR с записью в 1С — отдельное обсуждение, не по умолчанию.
2. **Один запрос — один шаблон HTTP-сервиса.** Новая функция = новый путь в `/hs/bilem/v1/…` + описание в `docs/api-v1.md` + инструмент в `mcp/`.
3. **Лимит 200 строк на ответ** и пагинация, если нужно больше.
4. Имена и стиль кода 1С — по [стандартам разработки 1С](https://its.1c.ru/db/v8std). Для MCP — `npm run lint`.
5. Коммиты и PR на русском, по сути: «cfe: /invoices — фильтр по контрагенту».

## Как прислать изменение

1. Форк → ветка от `main` (`feature/invoices-filter`).
2. Изменения + обновлённый `docs/api-v1.md`, если трогали API.
3. PR с описанием: что, зачем, как проверяли (конфигурация, версия платформы).
4. Ревью — [@VyacheslavBakanovExtraSoft](https://github.com/VyacheslavBakanovExtraSoft) по 1С, [@vprimin](https://github.com/vprimin) по MCP и облаку. Обычно отвечаем в течение пары дней.

Мелкие правки документации — можно сразу PR без обсуждения.

## Лицензия

Отправляя PR, вы соглашаетесь, что код публикуется под MIT, как и весь проект.
