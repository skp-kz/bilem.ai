# Как участвовать в bilem.ai

Спасибо, что заглянули. Проект открытый (MIT): здесь код **Bilem Agent** — программы для Windows, которая подключает 1С к ИИ-ассистентам через MCP.

## С чего начать

- Вопросы «как подключить», «не работает на моей конфигурации» — в [Discussions → Вопросы](https://github.com/skp-kz/bilem.ai/discussions/categories/q-a). Issues — только для подтверждённых ошибок и запросов функций.
- Идеи новых функций агента («хочу, чтобы отвечал про…») — [Discussions → Идеи](https://github.com/skp-kz/bilem.ai/discussions/categories/ideas). Там голосуем, что делать первым.
- Нашли уязвимость — **не** в публичный issue, см. [SECURITY.md](SECURITY.md).

## Структура

| Папка | Что |
| --- | --- |
| `src/Bilem.Agent.Core/` | вся логика без окна: подключение базы, OData-клиент, MCP-сервер и инструменты, печатные формы, почта, обновления |
| `src/Bilem.Agent/` | окно (WinForms) и командная строка `bilem-agent` |
| `src/Bilem.Agent.Com/` | помощники COM 1С (32 и 64 бит) — роли, состав OData, метаданные |
| `tests/` | тесты Core (xUnit) |
| `installer/` | MSI (WiX 5) |
| `build/`, `.github/workflows/` | сборка, релиз по тегу, подпись |
| `docs/` | онбординг, права, известные проблемы, заметки для разработчиков |

## Окружение

Windows, .NET SDK 8 (сборка проектов .NET Framework 4.8 без Visual Studio):

```
dotnet build Bilem.Agent.sln
dotnet test tests/Bilem.Agent.Core.Tests
```

Для проверки на живой базе — платформа 1С 8.3 с «Модулями расширения веб-сервера», IIS, файловая база (демо «Бухгалтерии для Казахстана 3.0» подходит). Подробно — [docs/development.md](docs/development.md).

## Правила

1. **Учёт не трогаем.** Никакого проведения и удаления документов; запись — только объекты белого списка и только где её включил пользователь на «Доступе».
2. **Только этот компьютер.** OData и MCP — 127.0.0.1; ничего не отправляем в сеть без явной просьбы пользователя.
3. **Персональные данные** — закрыты по умолчанию; документы физлиц — только внутри печатных форм.
4. **Лимит 200 строк на ответ** инструмента и пометка «показаны первые N из M».
5. Тексты для человека — в `Resources/Strings.resx`, по-русски. Без жирного шрифта в окне.
6. Коммиты и PR на русском, по сути: «print_reconciliation: разбивка по договорам».

## Как прислать изменение

1. Форк → ветка от `main`.
2. Изменения + тесты; `dotnet test` проходит.
3. PR с описанием: что, зачем, как проверяли (Windows, платформа и конфигурация 1С).
4. Ревью — [@VyacheslavBakanovExtraSoft](https://github.com/VyacheslavBakanovExtraSoft) по 1С и агенту, [@vprimin](https://github.com/vprimin) по продукту и облаку. Обычно отвечаем в течение пары дней.

Мелкие правки документации — можно сразу PR без обсуждения.
