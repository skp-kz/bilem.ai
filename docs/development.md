# Bilem Agent — для разработчиков

История и подробности для разработчиков (пользовательское описание — в [README](../README.md)).

Bilem Agent — программа для Windows, которая даёт ИИ-ассистентам (Claude, ChatGPT и другим) доступ к данным 1С через MCP. Агент читает базу 1С через стандартный интерфейс OData, опубликованный **только для этой машины** (127.0.0.1). Расширение в базу 1С не ставится, учёт не меняется.

## Статус

**v0.2 (в работе) — вкладка «Доступ»; пока не для рабочих баз.** Программа — `src/` (C#, .NET Framework 4.8, окно WinForms + командная строка). Прототипы, из которых она выросла, — в `spike/`: онбординг на PowerShell и MCP-сервер на Node.

## Требования

- Windows 10/11 или Windows Server 2016+ (с .NET Framework 4.8 — на 2008 R2 / 2012 R2 его нужно поставить), права администратора;
- платформа 1С:Предприятие 8.3 с компонентой «Модули расширения веб-сервера»;
- IIS — программа включит его сама (галочка «Включить IIS…» / флаг `--enable-iis`);
- файловая база 1С (серверные — в следующей версии), логин администратора 1С.

Проверено на «Бухгалтерии для Казахстана» 3.0 и 32-битной платформе 8.3.27.

## Bilem Agent v0.1

1. Скачайте `bilem-agent-<версия>.zip` (сборка GitHub Actions) и распакуйте в любую папку — все файлы должны лежать вместе.
2. Запустите `bilem-agent.exe` (попросит права администратора).
3. **Базы 1С → Добавить…** — выберите базу из найденных на компьютере или укажите папку, введите логин и пароль администратора 1С → **Подключить**. Окно «Настройка» покажет шаги; через несколько секунд — «Готово».
4. **MCP → Подключить к Claude Code** (или Claude Desktop, Cursor) — и спрашивайте: «сколько у нас денег на сегодня?».

При первом запуске программа создаёт ярлык «Bilem Agent» на рабочем столе и в меню «Пуск» (пересоздать — `bilem-agent shortcut`). MCP работает, пока открыто окно (крестик сворачивает его в трей; выход — правой кнопкой по значку в трее → «Выход») или через `bilem-agent serve`. Повторный запуск открывает уже работающее окно. Окно компактное (640 × 440, можно растянуть); размер и положение запоминаются для пользователя Windows (`%LOCALAPPDATA%\Bilem\window.json`), окно за пределами экранов возвращается на основной, сброс — меню значка в трее → «Сбросить размер окна».

**Доступ** — что видит ИИ: дерево разделов как в левом меню вашей 1С (из подсистем конфигурации), у каждого объекта галочки «Чтение» и «Запись». Галочка раздела — все его объекты; запись без чтения невозможна; «Зарплата и кадры» (персональные данные) закрыт. «Применить»: для ИИ — сразу; в 1С (состав OData, роли пользователя bilem — самые узкие по ПравоДоступа) — с паролем администратора 1С и автоматической проверкой.

**Bilem не меняет ваш бухгалтерский учёт: читает данные и готовит только счета, доверенности, акты сверки и карточки контрагентов — после вашего подтверждения, непроведёнными.** Запись можно включить только для них (белый список в коде: счёт на оплату покупателю, доверенность, акт сверки взаиморасчётов, контрагенты, банковские счета, договоры контрагентов); у остальных объектов — замок. По умолчанию запись выключена везде. Проведения и удаления в программе нет.

**Печатные формы** — логотип, печать и подпись (факсимиле) своей у каждой базы, подписант, текст в шапке счёта; «Пробный счёт…» — PDF любого из последних счетов. Инструмент MCP `print_invoice` делает PDF счёта на оплату, который уже есть в 1С («сделай PDF счёта № 4»), и отдаёт сам PDF в ответе (ресурсом) вместе с картинкой первой страницы; копия — в «Документы\Bilem\<база>\Счета». Картинки хранятся только на этом компьютере (`C:\ProgramData\Bilem\bases\<имя>\print`, доступ — администраторам). PDF — PDFsharp + MigraDoc (MIT), шрифт PT Sans (OFL, `assets/fonts`).

Если что-то не работает — вкладка **«Сервис»**: «Диагностика компонентов» (чек-лист всего стека с подсказками), «Собрать системную информацию» (в буфер обмена — для обращения), «Собрать отчёт для поддержки», «Сообщить о проблеме на GitHub». Техподдержка бесплатной версии — только через GitHub Issues.

Значок в трее показывает состояние: **зелёный** — работает, все базы отвечают; **жёлтый** — подключение (запуск, настройка или проверка базы; дольше 60 с — становится красным); **красный** — ошибка (MCP не запустился или база не отвечает — причина в подсказке при наведении); **серый** — офлайн (нет подключённых баз или MCP остановлен).

Что делает программа при подключении базы — те же шаги, что спайк (см. [docs/onboarding.md](docs/onboarding.md)), и ещё:
- у каждой базы свой пул IIS `Bilem_<имя>`, права на папку базы — только у него;
- пароль `bilem` — в DPAPI области LocalMachine, файл доступен только Администраторам и SYSTEM; пароль администратора 1С не хранится нигде;
- настройки — `C:\ProgramData\Bilem\config.json` (без данных из 1С), журналы — `C:\ProgramData\Bilem\logs\`.

### Командная строка

То же, что кнопки окна; код возврата 0 — успех, 1 — любая проверка не прошла:

```text
bilem-agent diag   --base <папка> [--admin <логин> [--password <пароль>]]   диагностика и план, ничего не меняет
bilem-agent setup  --base <папка> --admin <логин> [--password <пароль>] [--slug <имя>] [--enable-iis] [--reset-password]
bilem-agent verify [--slug <имя>] [--admin <логин>]                        чтение, запрет записи, 401, 403 (с --admin — роли bilem)
bilem-agent list                                                            подключённые базы
bilem-agent remove --slug <имя> [--drop-user --admin <логин>]              убрать базу (с --drop-user — и пользователя bilem)
bilem-agent serve                                                           MCP-сервер без окна
bilem-agent connect claude-code|claude-desktop|cursor                       прописать MCP в ИИ-клиента
bilem-agent url                                                             адрес MCP с токеном
bilem-agent access --slug <имя> [--load] [--read-on|--read-off|--write-on|--write-off <объекты>] [--admin <логин>]
                                                                            доступ, как вкладка «Доступ»
bilem-agent print --slug <имя> [--number <номер>] [--logo|--stamp|--sign <файл>] [--details --admin <логин>]
                                                                            PDF счёта на оплату (без номера — последний)
bilem-agent doctor                                                          диагностика компонентов (ничего не меняет)
bilem-agent sysinfo                                                         системная информация для техподдержки
bilem-agent shortcut                                                        ярлык на рабочем столе и в «Пуске»
```

Пароль администратора 1С — `--password`, переменная окружения `BILEM_1C_ADMIN_PWD` или ввод с клавиатуры.

### MCP

Адрес `http://127.0.0.1:8796/mcp/<токен>` — только с этой машины, без токена — 401, из браузера (заголовок Origin) — 403. В ответе любого инструмента — не больше 200 строк (`MaxRows` в config.json); если обрезано — пометка «показаны первые N из M, уточните запрос». Инструменты те же, что у прототипа (`list_bases`, `whoami`, `find_counterparty`, `cash_balance`); если баз несколько и база не названа — ответ сразу по всем базам с подписью базы у каждой строки. Журнал запросов — время, база, инструмент, длительность, итог, без данных ответа.

### Удалить

Для каждой базы — «Удалить» в окне или `bilem-agent remove --slug <имя> [--drop-user …]`; затем удалить папку программы и `C:\ProgramData\Bilem`.

### Сборка

```powershell
dotnet test tests/Bilem.Agent.Core.Tests -c Release
dotnet build Bilem.Agent.sln -c Release
./build/package.ps1 -Configuration Release    # artifacts/pkg/bilem-agent-<версия>.zip
```

## Права в вашей 1С

У пользователя Bilem в вашей 1С по умолчанию — **только чтение, запись запрещена, проверено.** Запись черновиков — только по белому списку и только если вы её включили на вкладке «Доступ». Роли — только «Чтение…» и базовые, без «Полных прав» и без права добавлять, изменять, проводить или удалять. При каждом подключении скрипт пробует создать документ и изменить справочник и останавливается с ошибкой, если 1С это разрешила. Подробно — [docs/rights.md](docs/rights.md).

## Как запустить спайк

> Пока спайк — только на **копии** базы.

1. Скопируйте базу в отдельную папку, например `C:\Bases\Demo`.
2. Откройте PowerShell от имени администратора.
3. Диагностика (ничего не меняет):

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\spike\setup-spike.ps1 -BasePath C:\Bases\Demo -AdminUser Администратор
   ```

4. Применение:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\spike\setup-spike.ps1 -BasePath C:\Bases\Demo -AdminUser Администратор -Apply -EnableIIS
   ```

   Пароль администратора 1С — в окне или в переменной окружения `BILEM_1C_ADMIN_PWD`.

5. В конце — «ГОТОВО» и адрес `http://127.0.0.1/bilem_demo/odata/standard.odata`.
6. Проверить уже подключённую базу ещё раз (ничего не меняет): та же команда с `-Verify` вместо `-Apply -EnableIIS`.

## Что спайк меняет на машине

Регистрирует COM-коннектор 1С (если нужно), включает компоненты IIS (с `-EnableIIS`), создаёт публикацию базы с доступом только с 127.0.0.1, пул IIS `Bilem1C` (анонимный вход публикации — от его имени), даёт права на папку базы только этому пулу; в базе — пользователь `bilem` и состав интерфейса OData. Пароль `bilem` случайный и хранится только в зашифрованном (DPAPI) файле в `C:\ProgramData\Bilem\spike\`. Подробно — [docs/onboarding.md](docs/onboarding.md).

## MCP-сервер (спайк)

`spike/mcp/` — минимальный MCP-сервер поверх OData: ИИ-ассистент задаёт вопрос, сервер читает 1С через OData и отвечает компактным JSON. Только чтение. Слушает **только 127.0.0.1**; адрес содержит токен: `http://127.0.0.1:8795/mcp/<токен>`. Без токена или с неверным — 401.

Инструменты:

| Инструмент | Что делает |
| --- | --- |
| `list_bases` | какие базы подключены: короткое имя, конфигурация, версия |
| `whoami` | конфигурация и версия базы, организации (наименование, БИН/ИИН), пользователь |
| `find_counterparty` | поиск контрагента по части наименования или БИН/ИИН, до 10 строк |
| `cash_balance` | остаток денег на конец дня по организациям: касса (1010), банк (1030–1050), прочие 10xx, итого — по плану счетов «Типовой» (БП КЗ) |

У каждого инструмента, кроме `list_bases`, есть необязательный параметр `base`. Если база одна — его можно не указывать; если несколько и не указан — сервер вернёт ошибку со списком баз.

### Запуск

Требуется Node.js 18+. Запускать под той же учётной записью Windows, что и `setup-spike.ps1`: пароль `bilem` расшифровывается из её DPAPI-файла.

```powershell
cd spike\mcp
npm install
node server.mjs          # сервер
node server.mjs --url    # адрес с токеном — для подключения клиента
```

Базы сервер берёт из описаний `*.base.json`, которые `setup-spike.ps1` пишет в `C:\ProgramData\Bilem\spike\` после успешной проверки (в описании нет пароля — только путь к DPAPI-файлу). Подключить не все — `BILEM_BASES=имя1,имя2`. Порт — `BILEM_MCP_PORT` (по умолчанию 8795). Токен создаётся при первом запуске и хранится в профиле пользователя: `%LOCALAPPDATA%\Bilem\spike\mcp-token`.

### Как подключить MCP к Claude Code / Claude Desktop / Cursor

Адрес с токеном — из `node server.mjs --url`. Токен никому не пересылайте и не коммитьте.

**Claude Code** (проверено):

```powershell
claude mcp add --transport http bilem-local "http://127.0.0.1:8795/mcp/<токен>"
```

**Claude Desktop** — локальные HTTP-серверы подключаются через мост `mcp-remote`; в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "bilem": { "command": "npx", "args": ["-y", "mcp-remote@0.14.3", "http://127.0.0.1:8795/mcp/<токен>"] }
  }
}
```

**Cursor** — в `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "bilem": { "url": "http://127.0.0.1:8795/mcp/<токен>" }
  }
}
```

Claude Desktop и Cursor в спайке не проверялись.

Спросите по-человечески: «какие базы подключены?», «что это за организация?», «найди контрагента …», «сколько у нас денег на сегодня?» — модель сама выберет инструмент.
